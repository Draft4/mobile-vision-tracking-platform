# 公共接口文档

本目录存放底盘、云台和视觉模块共同遵守的约定。任何会影响两个或更多模块的接口，都应在这里说明，不能只存在于某位成员的代码或聊天记录中。

## 当前文档

- [坐标系与方向约定](coordinate-system.md)：定义车体、云台、相机、图像坐标系，以及上下左右、角度和误差的正负方向。
- [RK3588 到 STM32 视觉测量通信协议](communication-protocol.md)：定义单向 UART 测量帧、任务标识、角度误差、CRC 和超时保护。

## 后续建议补充

- 实际 RK3588 与 STM32 型号确定后，补充 UART 排针、电平、设备节点和接线图；
- 完成实机性能测试后，固化发送频率、延迟指标和最终超时阈值；
- 确定整车开机模式选择方式后，再补充启动流程；需要双向通信或运行时切换任务时，再升级协议版本。

修改公共接口前，应先通知受影响模块的成员。接口代码与文档应尽量在同一个分支中更新。
